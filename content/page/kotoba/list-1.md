Twenty words you'll use every single day. Read them aloud first, then test yourself.

## Greetings

- <span lang="ja">おはよう</span> — *ohayou* (good morning, casual)
- <span lang="ja">こんにちは</span> — *konnichiwa* (hello, daytime)
- <span lang="ja">こんばんは</span> — *konbanwa* (good evening)
- <span lang="ja">さようなら</span> — *sayounara* (goodbye)
- <span lang="ja">ありがとう</span> — *arigatou* (thank you)
- <span lang="ja">すみません</span> — *sumimasen* (excuse me / sorry)

## Numbers 1–10

- <span lang="ja">いち</span> — *ichi* (1)
- <span lang="ja">に</span> — *ni* (2)
- <span lang="ja">さん</span> — *san* (3)
- <span lang="ja">よん</span> — *yon* (4)
- <span lang="ja">ご</span> — *go* (5)
- <span lang="ja">ろく</span> — *roku* (6)
- <span lang="ja">なな</span> — *nana* (7)
- <span lang="ja">はち</span> — *hachi* (8)
- <span lang="ja">きゅう</span> — *kyuu* (9)
- <span lang="ja">じゅう</span> — *juu* (10)

## Pronouns and Yes/No

- <span lang="ja">わたし</span> — *watashi* (I / me)
- <span lang="ja">あなた</span> — *anata* (you)
- <span lang="ja">はい</span> — *hai* (yes)
- <span lang="ja">いいえ</span> — *iie* (no)

## After This List

You should be able to:

- Greet someone at the right time of day.
- Count to ten.
- Refer to yourself and the person you're talking to.
- Answer yes or no.
